# Customer Support RAG

RU/EN-чат по публичной базе знаний Kaspersky.

Проект находит подходящие статьи, формирует краткий ответ со ссылками и отказывается отвечать, если в базе недостаточно информации.

## Возможности

- вопросы на русском и английском языках;
- гибридный поиск по смыслу и ключевым словам;
- ответы со ссылками на источники;
- история диалогов;
- безопасный отказ при нехватке информации;
- автоматическая проверка ответа.


## Последние результаты:

- Retrieval hit@3 — `94,3%`;
- ответы на поддерживаемые вопросы — `100% (18/18)`;
- корректный отказ вне базы — `100% (4/4)`;
- корректность ссылок и языка — `100%`;
- среднее время ответа — `6,85 с`.

Метрики получены на dev/regression-наборе и не заменяют ручную проверку фактической точности ответов.
